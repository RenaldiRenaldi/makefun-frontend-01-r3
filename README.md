Lantern is a fast dark make.fun board for pots, deadlines, bounties, leaderboards, and builder profiles.

## Run it

```sh
node serve.ts --port 8080
```

Visit `#/`, `#/bounty/threejs-fps-02`, `#/bounty/coolest-art-01/leaderboard`, and `#/u/renaldi`. The static app uses system fonts, ETag revalidation, session caching, and local pagination. No framework or build step is needed.

Package with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The Node 22 standard-library driver copies the app and three live browser screenshots, then calls the unchanged vendored dossier builder.
