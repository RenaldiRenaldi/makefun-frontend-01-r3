Browser-native modules and system typography keep the first load small. API responses use memory and session caches with ETag revalidation; lists paginate locally without additional requests.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts --port 8080
```
